# wechat-mini-program 微信小程序 - 青智益村 🏘️

青智益村 - 微信小程序项目

## 项目简介

青智益村是一个服务乡村的微信小程序，为村民提供便捷的服务。

## 项目结构

项目采用标准微信小程序开发结构。

## 使用说明

### 安装与运行

1. 在微信开发者工具中导入项目
2. 在 project.config.json 中填入你的 appid
3. 编译运行

### 注意事项

⚠️ project.config.json 和 project.private.config.json 包含敏感信息，请勿提交到公开仓库！
