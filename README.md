# 青智益村 · 微信小程序

乡村政务服务小程序（课程 / 实验项目）。

## 项目背景

做一个面向村民的政务服务入口，把常见的办事指引、信息查询放到小程序里，降低使用门槛。

## 项目结构

标准微信小程序开发结构（`pages` / `components` / `utils` 等）。

## 我的工作

- 搭建小程序基础框架
- 实现核心页面与交互
- 对接后端接口（如有）

## 运行方式

1. 在微信开发者工具中导入项目
2. 在 `project.config.json` 中填入你自己的 appid
3. 编译运行

## 注意事项

⚠️ `project.config.json` 和 `project.private.config.json` 可能包含敏感信息（appid / 本地配置），不要提交到公开仓库。本仓库已注意处理，如果你要 fork，请先确认没有泄露自己的配置。

## 项目不足

- 功能以演示为主，未接入真实政务后端
- 缺少测试用例
- 部分页面仍是占位实现

## 后续计划

- 视需要补充真实接口联调
- 完善权限与登录流程

## Reflection

第一次完整做一个小程序，熟悉了微信生态的开发流程、组件体系和审核机制，也意识到小程序和 Web 在状态管理上的差异。
